How to compile and run code:
  1. open the UploadServer folder and compile all java files using `javac *.java` in the terminal
  2. run UploadServer class with `java UploadServer` to run the site through localhost:8082 (leave this terminal open)
  3. open http://localhost:8082/ in a browser to see the upload form
  4. open a new terminal in the ConsoleApp folder and compile java files using the same command
  5. run the Activity class with `java Activity` (the server must be running) and see if it posts an image "dog" into the images folder
  6. uploaded files are saved in the images folder as caption_date_filename
